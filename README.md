# 熊猫烧香趣味桌宠

当前版本：**1.2.3**  
定位：一款致敬 2006 年经典梗图的桌面宠物。全部“感染、蓝屏、关机”效果都是**纯视觉玩笑**，不修改文件、不复制自身、不联网上报。

## 简介

熊猫烧香趣味桌宠是一只常驻桌面的透明小熊猫：可以拖动、投喂、摸头、戳肚子、聊天、求签、猜拳、看成就墙，也会在闲置时自己伸懒腰、打哈欠、跟着鼠标转头。心情不好时会用仿真蓝屏 / 关机 / 熊猫暴雨等方式“撒气”，但所有效果都只是窗口动画。

项目基于 Electron，启动脚本会自动清除环境中的 `ELECTRON_RUN_AS_NODE`，避免 Electron 被当成普通 Node 进程启动。

## 快速开始

环境要求：

- Node.js 18 或更高版本
- npm

```bash
npm install
npm start
```

启动后桌宠会置顶显示在桌面中央附近。拖动熊猫本体可移动位置；右键熊猫可打开完整功能菜单；左上角工具栏提供快速投喂、音效、设置和退出。

退出方式：

- 工具栏最右侧 `×`
- 设置面板底部“退出桌宠”
- 右键菜单没有退出项时，使用上述两种方式

## 操作速查

### 鼠标

| 操作 | 效果 |
| --- | --- |
| 按住熊猫拖动 | 移动桌宠，位置会自动保存 |
| 单击头顶一撮毛区域 | 摸头，连续摸有递进反应 |
| 单击身体 / 肚子 | 戳一戳，连续戳会触发痒痒动画 |
| 单击三炷香 | 抢香，香火和心情下降 |
| 点击工具栏“竹 / 香 / 梗” | 直接投喂 |
| 拖拽工具栏食物到熊猫身上 | 拖拽投喂，飞入动画 |
| 右键熊猫 | 打开完整功能菜单 |
| 香火告急时点击“上香” | 快速补充香火 |

### 键盘

| 快捷键 | 效果 |
| --- | --- |
| `Esc` | 关闭当前菜单 / 设置 / 成就墙 / 聊天 / 成长 / 关于面板 |
| `Ctrl+Alt+P` | 开启或关闭鼠标穿透 |
| `Ctrl+Alt+1` | 触发熊猫暴雨 |
| `Ctrl+Alt+2` | 触发仿真关机 |
| `Ctrl+Alt+3` | 触发仿真蓝屏 |
| `Ctrl+Alt+0` | 提前结束当前全屏彩蛋 |

三种全屏彩蛋都会铺满整个桌面（包括任务栏）；熊猫暴雨使用半透明暗色遮罩，能隐约看到原来的桌面。

## 设置项说明

设置面板中包含：

- **大小**：只缩放熊猫图片层，文字保持清晰；范围 70% 至 140%。
- **透明度**：调整整个桌宠窗口透明度。
- **窗口置顶**：控制是否始终显示在其他窗口之上。
- **鼠标穿透**：让鼠标事件穿过桌宠；开启后可用 `Ctrl+Alt+P` 恢复。
- **音效总开关**及三类分开关：提示音、音乐、彩蛋音。
- **开机自启**：写入系统登录项，默认关闭。
- **眼神跟随鼠标**：熊猫会轻微朝鼠标方向倾斜。
- **恶搞模式**：关闭后不高兴只表现为低沉待机，不会触发蓝屏等恶搞。
- **主题**：经典 / 春节 / 赛博。
- **小游戏区**：求签与石头剪刀布。
- **状态统计**：香火、心情、亲密、成就、聊天、上香次数。
- **退出桌宠**：结束程序。

所有设置和状态会自动保存到本地；下次启动会恢复。

## 数据与普通隐私

项目使用两类本地存储，不上传任何数据：

| 内容 | 位置 |
| --- | --- |
| 香火、心情、亲密度、成就、聊天、设置 | Electron `userData` 下的 localStorage，键名 `pandaIncensePetState` |
| 窗口位置与缩放 | Electron `userData/panda-window.json` |
| 明信片截图 | 用户通过保存对话框自行选择路径 |

如需“重置存档”，可在设置面板中退出后删除上述本地数据；程序下次启动会重新初始化。

## 宠物升级玩法

熊猫有独立的 10 级成长线，和软件版本无关。香火 / 心情条下方新增经验条，显示当前等级；右键“成长档案”可查看经验进度、等级称号、每级奖励和升级路线。

### 经验来源

| 行为 | 经验 |
| --- | --- |
| 投喂竹子 / 香 / 梗图 | 8 / 10 / 6，2 级后各 +1 |
| 摸头 / 戳肚子 | 2，不高兴时 1 |
| 聊天 | 4，8 级后 5 |
| 求签 / 今日签 / 签到 | 5 / 8 / 12，高等级有额外加成 |
| 猜拳 | 赢一局 10，打完整一局 4 |
| 决策助手 | 6，5 级后 8 |
| 跳舞 / 连点变异 | 3 / 5 |

### 等级路线

`香火学徒 → 闻香小童 → 拜年专员 → 护香童子 → 符咒实习生 → 香火判官 → 熊猫大仙 → 赛博道长 → 香火护法 → 熊猫烧香本体`

升级时会恢复香火与心情、播放升级光效和音效；5 级与 10 级分别解锁“初具道行”“香火化身”成就。部分等级还会真实解锁加成：投喂经验 +1、主动搭话更频繁、签到香火 +2、决策 / 求签经验加成、聊天经验 +1 等。

## 版本与升级系统

从 **1.1.0** 起，右键菜单“关于”会打开“关于与更新”面板：

- 显示当前版本、最新版本、更新源类型。
- 点击“检查更新”读取本地 `update.json`；如果配置了 `feedUrl`，会尝试从 HTTPS 地址读取远程清单。
- 有更新日志与可选“前往下载”按钮。
- 系统**不会自动下载或安装代码**，只会打开下载链接，避免不可控升级。

配置远程更新源：编辑项目根目录 `update.json`：

```json
{
  "version": "1.2.3",
  "released": "2026-11-21",
  "feedUrl": "https://example.com/panda-update.json",
  "downloadUrl": "https://example.com/panda-download",
  "notes": ["更新说明一", "更新说明二"]
}
```

`feedUrl` 必须返回同样结构的 JSON，且必须使用 HTTPS。若未配置或网络不可用，面板会回退为本地清单并显示原因。

## 项目结构

```text
panda/
├── assets/panda-classic.png   经典熊猫原图素材
├── docs/                      产品文档与说明书
├── launch.js                  清理 ELECTRON_RUN_AS_NODE 后启动 Electron
├── main.js                    主进程：窗口、拖拽、彩蛋、IPC、更新检查
├── renderer.js                渲染进程：状态、交互、聊天、游戏、音效
├── index.html                 主界面 DOM
├── styles.css                 布局、动画、主题与面板样式
├── swarm.html                 熊猫暴雨全屏彩蛋
├── shutdown.html              仿真关机全屏彩蛋
├── update.json                本地版本清单
├── package.json
└── CHANGELOG.md               版本记录
```
