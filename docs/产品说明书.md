# 熊猫烧香趣味桌宠 · 用户说明书

适用版本：**1.2.2**

## 1. 产品是什么

熊猫烧香趣味桌宠是一款运行在桌面上的电子宠物。它借用 2006 年“熊猫烧香”梗图的经典形象，但所有行为都是娱乐化、视觉化的：不会感染文件、不会自我复制、不会弹真实系统故障，也不会上传隐私数据。

它适合：

- 怀旧玩梗；
- 工作学习间隙的轻度互动；
- 收集成就、每日签到、聊聊天；
- 偶尔用仿真“系统故障”开个玩笑。

它不适合：

- 需要真实系统管理或安全软件功能的场景；
- 需要云同步、账号系统或多设备数据同步的场景。

## 2. 安装与启动

### 2.1 环境要求

- Node.js 18+
- npm
- Windows / macOS / Linux 桌面环境，需支持 Electron 窗口透明效果

### 2.2 安装

在项目根目录执行：

```bash
npm install
```

### 2.3 启动

```bash
npm start
```

项目中的 `launch.js` 会清除 `ELECTRON_RUN_AS_NODE` 环境变量后再启动 Electron。若直接用 `electron .` 遇到 `app is undefined`，请使用 `npm start`。

### 2.4 退出

- 点击工具栏最右侧 `×`；
- 打开设置面板，点击“退出桌宠”。

## 3. 界面区域

桌宠窗口是透明、无边框、置顶的小窗口，大致分为四层：

| 区域 | 说明 |
| --- | --- |
| 熊猫图片层 | 经典熊猫素材、烟雾 / 第三眼 / Zzz 叠层、点击热区、香火与心情条；缩放只影响这一层 |
| 文字 UI 层 | 工具栏、气泡、右键菜单、设置面板、聊天面板、成长档案、成就墙、关于面板、提示文字；不随图片缩放而模糊 |
| 特效层 | 心心、星星、熊猫头、梗图、音符、恶搞文字等临时动画 |
| 全屏彩蛋窗口 | 蓝屏、熊猫暴雨、仿真关机，由主进程单独创建，可覆盖整个桌面 |

### 3.1 状态条

熊猫脚下有两条状态：

- 一炷香图标：香火值；
- 爱心图标：心情值；
- 星形图标：宠物等级与当前等级经验进度。

图标旁边会显示当前数值或等级，鼠标悬停图标也可看到说明。香火较低时，熊猫旁边会临时出现“上香”救援按钮。

## 4. 基础互动

### 4.1 拖动桌宠

按住熊猫本体拖动即可移动窗口。拖动过程中工具栏和气泡会暂时隐藏，避免看起来像“按钮和熊猫分离”。放开后位置会自动保存到本地，下次启动仍在原处。

桌宠允许大部分窗口伸出屏幕边缘，只保留一小部分在屏幕内，因此可以在屏幕上下左右边缘停靠；极端多显示器布局下位置会被自动校正回可用区域。

### 4.2 分区点击

| 点击位置 | 反应 |
| --- | --- |
| 头顶 / 一撮毛 | 摸摸头，飘爱心，亲密度 +1（不高兴时反应冷淡） |
| 身体 / 肚子 | 戳一戳，连续戳会出现“痒痒”动画和递进台词 |
| 三炷香 | 抢香，香火 -3、心情 -2，并出现恶搞提示 |
| 背景透明区 | 不会触发熊猫点击，可穿透到桌面 |

连续摸头、连续戳肚子都有递进反馈；反复互动会累计统计并解锁成就。

### 4.3 投喂

工具栏左侧三个按钮：

- **竹**：喂竹子；
- **香**：添香；
- **梗**：喂梗图。

支持两种投喂方式：

1. 直接点击食物按钮；
2. 按住食物按钮拖到熊猫身上再松开。

投喂会有飞入动画、状态变化、提示音与台词。三种食物都喂过会解锁“三牲供奉”成就。

## 5. 状态与成长

### 5.1 香火值

香火代表熊猫的“精神供给”。它会随时间缓慢下降；通过添香、投喂、每日签到可以补充。香火过低时熊猫会不高兴，并出现救援按钮。

### 5.2 心情值

心情影响熊猫是否愿意互动：

- 心情较高：摸头、戳肚子、聊天会增加心情；
- 心情低于 30：进入不高兴状态，图像会变灰，心情条红色脉冲；
- 不高兴时：摸头 / 戳肚子不再有效哄人，聊天可能毒舌，若恶搞模式开启，自动行为会变成撒气彩蛋。

喂食、签到、道歉式聊天可以慢慢哄回来。

### 5.3 亲密度

亲密度通过聊天、投喂、摸头、决策助手等行为提升，共六级：

| 亲密度 | 等级 |
| --- | --- |
| 0 | 陌生 |
| 20 | 点头之交 |
| 50 | 熟悉 |
| 100 | 好友 |
| 200 | 亲密 |
| 300 | 心有灵犀 |

等级提升会有提示、星星特效和成就。亲密度还会解锁不同的主动搭话台词：关系越熟，熊猫越会自己找话说。

### 5.4 宠物等级

宠物等级是独立于亲密度和软件版本的成长玩法。右键“成长档案”可查看：

- 当前等级、称号与已解锁特权；
- 当前经验和距离下一级还需多少经验；
- 1 至 10 级的完整奖励路线。

等级路线：

| 等级 | 称号 | 解锁效果 |
| --- | --- | --- |
| 1 | 香火学徒 | 基础互动 |
| 2 | 闻香小童 | 投喂经验 +1 |
| 3 | 拜年专员 | 主动搭话更频繁 |
| 4 | 护香童子 | 签到额外香火 +2 |
| 5 | 符咒实习生 | 决策经验 +2，解锁“初具道行” |
| 6 | 香火判官 | 求签经验 +2 |
| 7 | 熊猫大仙 | 升级时回复更多心情 |
| 8 | 赛博道长 | 聊天经验 +1 |
| 9 | 香火护法 | 签到经验 +3 |
| 10 | 熊猫烧香本体 | 终极称号，解锁“香火化身” |

经验主要来自投喂、摸头、戳肚子、聊天、求签、今日签、签到、猜拳、决策助手、跳舞和变异。升级时会恢复香火与心情，并播放专属光效、音效和升级提示。

## 6. 聊天系统

右键熊猫选择“聊聊天”打开聊天面板。

### 6.1 输入与回复

输入文字后按回车或点击“发送”。熊猫会按关键词分类回复，例如：

- `你好` / `hi` / `哈喽`：打招呼；
- `叫我小明` / `我叫小明`：记住名字；
- `讲个笑话` / `冷笑话`：讲段子；
- `吃什么` / `饿`：聊吃的；
- `夸夸我` / `厉害`：夸你；
- `再见` / `拜拜`：告别；
- `帮我选A还是B`：触发决策风格回复。

无法识别时，熊猫会随机闲聊。若心情低且恶搞模式开启，会改为毒舌回复。

### 6.2 记忆范围

熊猫会记住：

- 你让它记住的名字；
- 最近一个话题；
- 最近 20 轮对话。

这些数据只保存在本机浏览器风格的 localStorage 中，不上传。

### 6.3 主动搭话

亲密度达到“熟悉”后，聊天面板打开时熊猫偶尔会自动插入一句；亲密度更高时，桌面待机也会主动说一句，概率随亲密度提升。

## 7. 小游戏与收集

### 7.1 求签

在设置面板或右键菜单中求签，会出现卷轴式签文和红色印章。签文有多种等级和文本。

### 7.2 今日签

每天第一次领取的签文由日期决定，同一天重复查看结果一致。今日签会加入签文收藏册。

### 7.3 石头剪刀布

在设置面板小游戏区出拳，与熊猫进行三局两胜。比分和胜负卡片会显示在结果区，赢下整局解锁成就。

### 7.4 决策助手

右键选择“帮我决定”，熊猫会给出带动画的裁决，例如选 A、选 B、两个都选、睡一觉再说等。它会增加亲密度并解锁“抉择时刻”成就。

### 7.5 成就墙

右键“成就墙”打开面板，共 23 个成就，覆盖首次点击、求签、猜拳、彩蛋、签到、聊天、亲密度、连续摸头 / 戳肚子、宠物 5 级 / 10 级等。下方还有签文收藏册，显示已收集 / 总数。

### 7.6 每日上香

右键“每日上香”可签到。连续签到天数越多，香火奖励越高；连续 3 天解锁“三日香客”。

## 8. 彩蛋与恶搞

所有彩蛋都是**视觉动画**，不会真实感染、删除、修改文件，也不会真的关机。

| 彩蛋 | 表现 | 时长 | 提前结束 |
| --- | --- | --- | --- |
| 熊猫暴雨 | 全屏系统警告风格，大量熊猫头下落、弹跳、大小随机 | 约 8.5 秒 | `Ctrl+Alt+0` |
| 仿真蓝屏 | Windows 风格蓝屏，错误码、进度条、二维码块 | 约 7 秒 | `Ctrl+Alt+0` |
| 仿真关机 | 旋转点阵、“正在关机”、步骤轮播、淡出 | 约 9.5 秒 | `Ctrl+Alt+0` |
| 随机捣乱 | 气泡吐槽、熊猫头、扣香火等轻量恶搞 | 即时 | 关闭恶搞模式 |
| 变异熊猫 | 连点 10 次触发，持续约 10 秒 | 10 秒 | 自动结束 |
| 跳舞 | 播放旋律与音符粒子 | 短时 | 自动结束 |

三种全屏彩蛋都会覆盖整个桌面，包括底部任务栏：蓝屏与关机为不透明全屏窗口，熊猫暴雨为半透明暗色遮罩（桌面隐约可见）。即使焦点不在桌宠上，也可以随时按 `Ctrl+Alt+0` 结束当前彩蛋。

设置中关闭“恶搞模式”后，不高兴的熊猫只会低沉待机，不会触发蓝屏、关机等强恶搞。

## 9. 设置面板详解

右键“设置”或工具栏 `设` 打开。

| 项目 | 作用 |
| --- | --- |
| 大小 | 70% 至 140%，只缩放熊猫图片层，文字保持清晰 |
| 透明度 | 40% 至 100% |
| 窗口置顶 | 是否始终浮在其他窗口之上 |
| 鼠标穿透 | 鼠标事件穿过桌宠；用 `Ctrl+Alt+P` 恢复 |
| 音效总开关 | 一键静音 |
| 提示音 / 音乐 / 彩蛋音 | 分别控制点击喂食、跳舞旋律、彩蛋音效 |
| 开机自启 | 写入系统登录项，默认关闭；启动时会同步系统真实状态 |
| 眼神跟随鼠标 | 熊猫头部轻微朝鼠标方向倾斜 |
| 恶搞模式 | 控制强恶搞彩蛋是否允许触发 |
| 主题 | 经典 / 春节 / 赛博 |
| 小游戏区 | 求签、石头剪刀布 |
| 状态统计 | 查看香火、心情、亲密、等级、经验、成就、聊天、上香数据 |
| 退出桌宠 | 结束程序 |

## 11. 数据存储与重置

### 11.1 存储内容

| 内容 | 存储位置 |
| --- | --- |
| 状态、设置、成就、统计、聊天、收藏 | localStorage，键名 `pandaIncensePetState` |
| 窗口位置、缩放 | `userData/panda-window.json` |
| 明信片 | 用户通过保存对话框指定路径 |

Electron `userData` 目录通常位于：

- Windows：`%APPDATA%\panda-incense-pet`
- macOS：`~/Library/Application Support/panda-incense-pet`
- Linux：`~/.config/panda-incense-pet`

### 11.2 离线衰减

程序会记录上次活跃时间。关闭程序一段时间后再次启动，香火和心情会按离线时长衰减，并立刻写回存档，避免每次启动重复计算。

### 11.3 重置

若想从零开始：

1. 退出桌宠；
2. 删除 `userData` 下的 `panda-window.json`；
3. 删除 Electron `userData/Local Storage` 中本站点的 `pandaIncensePetState`；
4. 重新启动。

项目没有云同步，所有数据仅在本机。

## 12. 版本与更新

右键“关于”打开“关于与更新”面板。

- 显示当前版本和最新版本；
- 显示更新源类型（本地清单 / 在线更新源 / 检查失败）；
- 点击“检查更新”读取 `update.json`，若配置 `feedUrl` 则请求 HTTPS 更新清单；

- 不会自动下载或安装任何代码。

配置方式见根目录 `README.md` 的“版本与升级系统”章节。

## 13. 常见问题

### 13.1 启动时提示 `app is undefined`

原因是环境变量 `ELECTRON_RUN_AS_NODE=1` 导致 Electron 被当成 Node 运行。请使用 `npm start`，它会通过 `launch.js` 清除该变量。

### 13.2 按钮看起来离熊猫很远

按钮与熊猫在同一个透明窗口内，窗口整体移动时按钮会跟随。拖动时按钮会暂时隐藏；缩放时只缩放图片层，文字保持原尺寸。如果中心仍偏移，程序会在启动、窗口 resize 后重新测量熊猫中心并校正按钮位置。

### 13.3 无法往下拖到屏幕底部

拖拽允许透明留白伸出屏幕，只保留约四分之一窗口在屏幕内。若被系统多显示器布局限制，位置会被校正到最近可用区域。

### 13.4 彩蛋结束后没有回到桌宠

按 `Ctrl+Alt+0` 可提前结束当前彩蛋。正常情况下彩蛋窗口会在 7 至 9.5 秒后自动关闭，并回到桌宠。

### 13.5 关闭恶搞后还会不会撒气

不会触发蓝屏、关机、熊猫暴雨等强恶搞；不高兴只会表现为灰度外观、红色心情条和低沉台词。

### 13.6 数据会不会上传

不会。项目没有账号、没有网络上报、没有云同步；只有在使用“检查更新”且配置了 `feedUrl` 时，才会向该 HTTPS 地址请求版本清单。

### 13.7 自测没有输出或卡住

如果之前用超时方式强制结束过程，可能残留旧的 Electron 进程并占用同一用户数据目录。先结束所有来自本项目的 `electron.exe` 进程，再重新运行：

```bash
PANDA_SELFTEST=1 node launch.js
```

正常输出应包含 `RENDERER SELFTEST: OK`。

## 14. 安全与合规声明

- 所有“感染 / 蓝屏 / 关机”效果都是浏览器窗口和 CSS 动画；
- 不修改系统文件、不写注册表关键项、不创建自复制；
- 不收集键盘输入、不读取剪贴板、不上传聊天内容；
- 开源素材仅作怀旧玩梗，商业使用前请自行确认素材授权。

如发现异常行为，请优先检查是否运行了修改过源码的第三方版本。
